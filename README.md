### 🚀 Featured Projects

#### 1. DocuMind AI – Multi-PDF RAG Assistant

An AI-powered document intelligence application that allows users to upload multiple PDFs and interact with their content.

- Implemented PDF extraction, text chunking, embeddings, and semantic retrieval.
- Integrated Google Gemini embeddings, FAISS, and Groq API for context-aware question answering.
- Developed features including document summaries, flashcards, quizzes, and document comparison.
- Built the frontend using React.js and Vite and backend using Python and FastAPI.
- Deployed using Vercel and Render.

**Tech Stack:** Python, FastAPI, React.js, Vite, FAISS, Gemini API, Groq API.

🔗 [GitHub Repository](https://github.com/M-KESAV/multi-pdf-chatbot-DocuMind-AI)  
🌐 [Live Demo](https://multi-pdf-chatbot-docu-mind-ai.vercel.app/)

#### 2. Multi-Agent AI Research System

A multi-agent research application that automates web research and generates structured reports.

- Built AI-powered research workflows using LangChain and Google Gemini.
- Integrated Tavily for web search and content discovery.
- Developed REST APIs using FastAPI and implemented streaming progress updates.
- Used SQLite for data persistence and React with TypeScript for the frontend.

**Tech Stack:** Python, LangChain, Google Gemini, Tavily, FastAPI, SQLite, React, TypeScript.

🔗 [GitHub Repository](https://github.com/M-KESAV/LangChain-Multi-Agent-Research-System)  
🌐 [Live Demo](https://lang-chain-multi-agent-research-sys.vercel.app/)

#### 3. Vehiql – AI-Enhanced Car Marketplace

A full-stack car marketplace application with AI-powered vehicle discovery.

- Developed vehicle search, filtering, saved cars, and test-drive booking features.
- Implemented authentication and database management.
- Integrated Gemini API for image-based vehicle search.
- Built the application using Next.js, React, PostgreSQL, Prisma, Clerk, and Supabase.

**Tech Stack:** Next.js, React.js, PostgreSQL, Prisma, Clerk, Supabase, Gemini API.

🔗 [GitHub Repository](https://github.com/M-KESAV/Vehiql)  
🌐 [Live Demo](https://vehiql-tau.vercel.app/)

#### 4. Vision Assist AI – Wearable Accessibility Device

An AI-powered wearable vision assistance solution designed to help visually impaired users understand their surroundings through audio descriptions.

- Designed a wearable vision device using ESP32-CAM hardware.
- Integrated camera hardware with Google Gemini API for image analysis.
- Developed real-time image-to-audio assistance for hands-free navigation.
- Focused on building an affordable AI-powered accessibility solution.

**Tech Stack:** ESP32-CAM, Next.js, Google Gemini API, Power Bank.

🔗 [GitHub Repository](https://github.com/M-KESAV/Vision-Assist-AI)
